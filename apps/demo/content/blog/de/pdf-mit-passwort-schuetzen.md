Sie wollen gleich eine Gehaltsabrechnung, eine Steuererklärung oder einen Scan Ihres Reisepasses per E-Mail verschicken. Mit einem Passwort auf dem PDF kann niemand die Datei ohne dieses Passwort lesen, auch wenn die E-Mail im falschen Postfach landet oder die Datei in einem geteilten Ordner liegt.

## So fügen Sie ein Passwort hinzu

1. Öffnen Sie den Editor und wählen Sie Ihr PDF aus.
2. Öffnen Sie über den Pfeil neben **Herunterladen** die weiteren Speicheroptionen und wählen Sie **Mit Passwort**.
3. Geben Sie das Passwort ein und tippen Sie es unter **Passwort wiederholen** ein zweites Mal.
4. Klicken Sie auf **Herunterladen**. Die geschützte Kopie wird unter demselben Namen gespeichert.

Das war’s. Wer die Datei öffnet, ob in Acrobat, Vorschau, Chrome, Edge oder auf dem Handy, wird zuerst nach dem Passwort gefragt.

Sie können das PDF bearbeiten, bevor Sie es schützen: Text ändern, unterschreiben, das Formular ausfüllen. All das ist in der geschützten Kopie enthalten.

## Wie sicher ist das?

Die Datei wird mit **AES-256** verschlüsselt, dem stärksten Verfahren, das PDFs unterstützen, und demselben, das auch Acrobat verwendet. Ohne Passwort ist der Inhalt unlesbarer Datensalat, nicht bloß versteckt.

Das Passwort ist allerdings nur so stark, wie Sie es wählen. Ein kurzes Wort kann ein Programm erraten, das Millionen davon durchprobiert. Nehmen Sie eine Folge aus drei oder vier Wörtern oder eine Mischung aus Buchstaben, Zahlen und Sonderzeichen mit mindestens 12 Zeichen.

## Schicken Sie das Passwort auf anderem Weg

Wenn Sie die Datei per E-Mail verschicken, schreiben Sie das Passwort nicht in dieselbe E-Mail. Schicken Sie es per SMS, sagen Sie es am Telefon oder senden Sie es über eine andere App. Sonst hat jeder, der die E-Mail bekommt, beides.

## Bewahren Sie das Passwort gut auf

Bei einem PDF gibt es kein „Passwort vergessen“. Das Passwort wird nirgends gespeichert, deshalb kann es niemand für Sie wiederherstellen, auch wir nicht. Legen Sie es in Ihrem Passwort-Manager ab, bevor Sie die Datei verschicken.

## Warum im Browser?

Die meisten Online-Tools, die ein Passwort hinzufügen, laden Ihre Datei zuerst auf ihren Server hoch. Das ungeschützte PDF läuft also über den Computer eines anderen, und genau das wollen Sie ja vermeiden.

Hier geschieht die Verschlüsselung auf Ihrem Gerät. Das PDF wird nie irgendwohin geschickt, weder vor noch nach dem Sperren.
