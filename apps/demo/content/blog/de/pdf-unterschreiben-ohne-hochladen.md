Ein Arbeitsvertrag, ein Mietvertrag, ein medizinisches Formular: Die Dokumente, die wir unterschreiben, gehören zu den privatesten, die wir haben. Trotzdem heißt online unterschreiben meist, das Dokument auf eine Website hochzuladen, die zumindest eine Zeit lang eine Kopie auf ihren Servern behält.

Es geht auch anders. Ein moderner Browser kann ein PDF selbst öffnen, bearbeiten und speichern, ohne dass irgendetwas verschickt wird.

## So unterschreiben Sie

1. Öffnen Sie die Seite **PDF unterschreiben** und wählen Sie Ihr PDF aus.
2. Fügen Sie Ihre Unterschrift hinzu: Mit **Zeichnen** zeichnen Sie sie mit Maus, Trackpad oder Finger, mit **Tippen** schreiben Sie Ihren Namen in einer Handschrift, und mit **Foto** verwenden Sie ein Foto Ihrer Unterschrift auf Papier.
3. Klicken Sie auf **Unterschrift platzieren** und dann auf die Stelle, an die sie gehört. Ziehen Sie sie an die richtige Position und ändern Sie die Größe an der Ecke.
4. Brauchen Sie auch Initialen oder ein Datum? Wählen Sie **Notiz** und tippen Sie sie an eine beliebige Stelle der Seite.
5. Klicken Sie auf **Herunterladen**. Das unterschriebene PDF wird auf Ihrem Gerät gespeichert.

## So prüfen Sie, dass nichts hochgeladen wird

Sie müssen uns nicht beim Wort nehmen. Probieren Sie Folgendes:

1. Öffnen Sie das PDF im Editor.
2. Schalten Sie Ihr WLAN aus oder aktivieren Sie den Flugmodus.
3. Unterschreiben Sie, platzieren Sie die Unterschrift und laden Sie das PDF herunter.

Alles funktioniert weiterhin, denn sobald die Seite und Ihre Datei geöffnet sind, braucht nichts mehr das Internet. Ein Werkzeug, das Ihr Dokument hochlädt, kann das nicht.

## Wo landet meine Unterschrift?

Ihre letzten drei platzierten Unterschriften werden gespeichert, damit Sie sie wiederverwenden können, und zwar im Speicher Ihres Browsers auf diesem Gerät. Sie werden nie an uns gesendet. Wenn Sie die Websitedaten in Ihrem Browser löschen, sind sie entfernt.

## Ist das rechtsgültig?

In den meisten Ländern gilt ein Bild Ihrer Unterschrift auf einem PDF als elektronische Signatur, und genau das erwarten die meisten alltäglichen Unterlagen: Mietverträge, Schulformulare, Personalunterlagen und viele Verträge.

Manche Dokumente verlangen eine qualifizierte elektronische Signatur, die auf einem für Sie ausgestellten Zertifikat beruht. Das ist eine andere, kryptografische Art der Signatur, und sie wird hier noch nicht unterstützt. Verlangt der Absender eine solche Signatur, nutzen Sie den Dienst, den er nennt.
